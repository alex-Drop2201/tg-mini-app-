# CLAUDE.md

## Владелец и формат работы

- Владелец общается по-русски и работает только с iPhone, без компьютера. Отвечай по-русски, коротко.
- Тексты интерфейса тоже на русском.
- Владелец не может сам запустить код, поэтому результат UI-изменений показывай скриншотом (см. ниже).
- Владелец выбрал работу без PR: проверенные правки заливаются прямо в `main`, когда он об этом просит.

## Проект

Два Telegram Mini App на React 19 + TypeScript + Vite в одном репозитории (многостраничная сборка Vite):
«Колесо решений» (`index.html`, корень сайта) и «Питомец», тамагочи (`pet/index.html`, путь `/pet/`).
У каждого свой бот. Деплой на GitHub Pages через `.github/workflows/deploy.yml` при push в `main`
(только если репозиторий публичный). Общий код (`src/telegram.ts`, `src/storage.ts`,
`src/useStoredState.ts`, `src/base.css`) меняй с оглядкой на оба приложения.
Планы по этапам с отметками о готовности лежат в README: после этапа обновляй галочки.

Колесо:
По умолчанию колесо «в стиле Telegram» (оттенки цвета кнопки из темы), в настройках есть палитры и свои цвета (`src/colors.ts`).
Настройки открываются из меню ⋯ Telegram (SettingsButton), назад — родной BackButton; в браузере есть свои кнопки.

Питомец (`src/pet/`): владелец выбрал мягкий уход — питомец грустит, но не умирает и не убегает.
Хранится только снимок состояния после действия; текущее состояние досчитывается от снимка
(`simulate` в `model.ts`), поэтому время идёт и при закрытом приложении. Проверка модели —
быстрым node-скриптом поверх `model.ts` (Node 22 сам снимает типы с .ts).
Внешность (`look` в снимке): виды рисуются в SVG по общей схеме `critter/anatomy.tsx`
(части тела + точки крепления), анимации общие в `pet.css`. Новый вид = запись в `ANATOMY`
и в `SPECIES` (`look.ts`); новый аксессуар = запись в каталоге `look.ts` и рисунок в `accessories.tsx`.
Неизвестные значения внешности из облака заменяются стандартными (`parseLook`).
Владелец просил «очень классное оформление»: новые экраны питомца делай на том же уровне.

- Доступ к Telegram API только через `src/telegram.ts`. Типы: `@types/telegram-web-app`.
- Код обязан работать и без Telegram: в обычном браузере `window.Telegram` может отсутствовать
  или иметь пустой `initData`.
- Цвета интерфейса берутся только из CSS-переменных `--tg-theme-*` с фолбэками (см. `src/base.css`).
  Исключения — палитры секторов колеса (`src/colors.ts`) и рисунки питомца: окрасы, фоны,
  аксессуары, цвета шкал (`src/pet/`).
- В Vite стоит `base: './'`: никаких абсолютных путей к ассетам. Если понадобится роутинг, используй hash-роутинг.
- Фронтенд публичный: токены ботов и прочие секреты в репозиторий не коммитить.

## Проверка перед коммитом

```bash
npm run lint && npm run build
```

Для UI-изменений: `npm run preview` (порт 4173, такса — по пути `/pet/`) и скриншот через Playwright
(`/opt/node22/lib/node_modules/playwright`, Chromium уже установлен) с viewport 390×700
в светлой и тёмной теме, затем отправь его владельцу. Домены telegram.org из облачного
контейнера заблокированы, поэтому ошибка загрузки `telegram-web-app.js` в превью ожидаема.
