# Мини-приложения для Telegram

Два Telegram Mini App на React + TypeScript + Vite. Сайт публикуется на GitHub Pages
и открывается внутри Telegram на любом телефоне, включая iPhone.

- **Колесо решений**: `https://alex-drop2201.github.io/tg-mini-app-/`
- **Такса** (тамагочи): `https://alex-drop2201.github.io/tg-mini-app-/pet/`

У каждого приложения свой бот. Облако Telegram хранит данные отдельно для каждого бота.

## Как работать с телефона

1. Пишете в Claude Code, что нужно поменять.
2. Claude правит код, собирает его и показывает скриншот.
3. После попадания изменений в `main` GitHub Actions за 1–2 минуты обновляет сайт.
4. Открываете бота в Telegram и проверяете.

Компьютер не нужен.

## Первоначальная настройка (один раз)

Настройки репозитория меняются только через сайт. Откройте github.com в браузере телефона,
а не в приложении GitHub, и зайдите в репозиторий → **Settings**.

1. **General → Repository name**: короткое имя латиницей, например `tg-mini-app`.
2. **Описание**: значок ⚙️ рядом с About на главной странице репозитория.
3. **General → Danger Zone → Change visibility → Public.** На бесплатном плане
   GitHub Pages работает только у публичных репозиториев. Код Mini App всё равно
   скачивается в браузер, но **токен бота и другие секреты сюда не коммитим никогда**.
4. **Pages → Build and deployment → Source: GitHub Actions.**
5. **Actions → Build & Deploy → Run workflow.** После завершения оба приложения доступны
   по адресам выше (они меняются вместе с именем репозитория).

### Подключить к боту

Для каждого приложения свой бот:

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`, чтобы создать бота.
2. `/mybots` → ваш бот → **Bot Settings → Menu Button** → вставьте адрес приложения.
3. Откройте своего бота: Mini App запускается кнопкой у поля ввода.

## Структура

Общее для обоих приложений:
- `src/telegram.ts`: доступ к `Telegram.WebApp`, вибрация, проверка «открыто ли в Telegram».
- `src/storage.ts`: Telegram CloudStorage, а в браузере localStorage.
- `src/useStoredState.ts`: состояние с сохранением в облако Telegram.
- `src/base.css`: цвета темы Telegram (`--tg-theme-*`), кнопки, карточки, списки.
- `.github/workflows/deploy.yml`: сборка на каждый push и PR, деплой на Pages из `main`.

Колесо (`index.html`):
- `src/App.tsx`: загрузка данных и переключение экранов.
- `src/screens/WheelScreen.tsx`: главный экран: колесо, результат, кнопка, редактор.
- `src/screens/ColorsScreen.tsx`: настройки цветов: палитры и свои цвета.
- `src/colors.ts`: палитры, раскраска секторов, цвет текста под фон.
- `src/useTelegramNavigation.ts`: «Настройки» в меню ⋯ и кнопка «Назад» в шапке Telegram.
- `src/wheel/spin.ts`: математика: честный случайный выбор и угол остановки.
- `src/wheel/useSpin.ts`: анимация вращения и вибрация на каждом секторе.
- `src/wheel/Wheel.tsx`: колесо в SVG.
- `src/OptionsEditor.tsx`: список вариантов.
- `src/options.ts`: варианты по умолчанию, лимиты, загрузка и сохранение.
- `src/index.css`: стили колеса.

Такса (`pet/index.html`):
- `src/pet/model.ts`: шкалы, течение времени, сон, действия и отказы, настроение.
- `src/pet/usePet.ts`: питомец «вживую»: пересчёт раз в секунду и сохранение после действий.
- `src/pet/Dachshund.tsx`: такса в SVG с эмоциями, миской, мячиком, пеной и сердечками.
- `src/pet/PetApp.tsx`: экраны знакомства и ухода.
- `src/pet/pet.css`: стили и анимации таксы.
